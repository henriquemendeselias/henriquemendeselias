### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/People/Technologist.png" width="30" alt="Dev"> Sobre Mim

Sou graduando em **Engenharia de Software na Universidade de Brasília (UnB)**, com foco sólido em **Engenharia de Dados**. Em ambiente **Ubuntu Linux**, dedico-me a arquitetar e implementar pipelines resilientes e sistemas de alta performance que transformam dados brutos em inteligência estruturada de forma rápida e segura.

Minha atuação combina o desenvolvimento de pipelines de dados, modelagem relacional e implementação de bancos vetoriais (**Qdrant Cloud**) para aplicações de IA (RAG) com engenharia backend eficiente. Além do foco técnico, exerço liderança ágil como **Scrum Master** e contribuo para o desenvolvimento acadêmico atuando como **Tutor de Cálculo 3** na universidade.
